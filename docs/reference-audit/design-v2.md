2026-10-25。用户确认私有金额指 VPS 购买/续费成本。本轮仅审查与设计，未改变线上站点或权限。

## 页面检查

1. 首页正常加载（01-overview.png）：11 台、4 地区，上下行、日流量、热点、地球与资源卡片完整。地球占首屏较多，节点只给一个延迟值。存在丢包的节点仍显示“卓越”，应将运行与线路状态分开。
2. 网络页正常加载（02-network.png）：已配置上海电信/联通/移动，电信/移动另有 IPv6；三网延迟及丢包已能显示。默认 22 条目标曲线过密，建议默认上海三网 IPv4，其余分组切换。
3. 浅金小字可能影响阅读，需后续测量对比度、测试键盘与手机重排；未进行登录与完整无障碍验证。

## 布局

顶栏：总览、网络质量、资源/流量、IP 质量；所有者登录后出现成本与续费。

首屏：在线/总节点、异常线路、今日流量、实时双向速率，小型地区概览和 7 天流量；地球可折叠。

主区域采用比较表：节点/地区、上海电信延迟与丢包、上海联通延迟与丢包、上海移动延迟与丢包、双向速率、资源占用、周期流量、IP 摘要。手机每张卡保留三网三行。详情再展开网络、资源、流量、IP。

三网按 tri_isp.targets 的 key 关联 ping[].key，不按可改名称关联。缺失显示无数据，不得用其他国际目标冒充上海三网。IPv4/v6 分开。标明探测方向、方式、时间窗口；服务器到探测目标不等于用户实际代理体验，国际连通性不等于解锁检测。只在专用 unlocks 数据存在时显示解锁。按 history_days 提供历史范围；桶数据不得杜撰包级 P95 或抖动。

可复用 daily_traffic、traffic_used/limit、period_start/end、conn_history、return_routes、unlocks。加入流量余量、重置日、最后在线、更新时间；字段缺失显示 —，遵守主控开关。0 限额表示不限。区分 B/s 与 Mbps。

## 私有成本

公开接口必须去除 renewal_price、renewal_price_cny、renewal_currency、renewal_cycle 及成本汇总；精确到期日和购买备注建议也仅所有者可见。采用公开字段白名单。所有者接口需要服务端身份和角色验证，no-store，不得把私有数据放静态文件、公共缓存或 localStorage。

当前 Worker 对 HTTP 和 WebSocket 原样透传，隐藏 React/CSS 无法保密。必须同时处理 HTTP 和 WS：WS 中继清洗或停用公开 WS 改过滤轮询。现有 PasskeyLogin 是跳转主控，不是本 Worker 的所有者会话。普通登录用户也不能读成本。测试匿名 HTTP/WS、普通用户、所有者、退出、缓存、classic 入口。

私有页：原币续费价/周期、人民币折算、月均/年均、30/60/90 天续费、供应商链接。年付月均不等于本月实际支出。购买价与付款历史要新增私有数据，不能由续费价猜测。

## IP 质量

- IPinfo：归属、ASN、用途、hosting/VPN/proxy（套餐决定字段）。
- Scamalytics：欺诈风险分、风险等级、报告链接。
- AbuseIPDB：指定窗口的滥用置信度、报告数、最近报告时间。

分别显示来源、原始分值、查询时间与过期状态，不合成无依据“纯净度”；住宅/机房标签不等于性能保证。使用官方 API，核对套餐与公开展示许可；后端定时查询和缓存，建议起步 24 小时，出口变更立即重查。查询失败显示旧值与过期标识，不能将失败当低风险。

公开探针不含 IP 与 ID，需要后台维护 opaque 稳定节点标识与真实出口 IP 的私有映射。不能用数组下标/可改名称长期绑定。服务器入口与代理出口可能不同，多落地及 IPv4/v6 各自记录。

报告深链通常暴露完整 IP。公开页默认仅摘要和来源首页，具体 IP 报告链接仅所有者可见；未来明确允许公开 IP 后再开放深链。URL 用固定来源模板或域名白名单生成。第三方 API key 不放前端。

## 实施顺序

2. 补全现有数据、首页三网矩阵与三条默认曲线。
3. 私有成本/续费页。
4. IP 映射、第三方缓存与来源链接。
